# 18. 개발 로드맵 (Phase별 · DoD 포함)

> **진행 규칙**: Phase는 순차 진행. 각 Phase 종료 시 DoD 체크리스트를 출력하고, 미달 항목을 먼저 해결한다 (R8).

## Phase 0 — 기반 (1주)
**작업**: Next.js 15 + TS + Tailwind 세팅 / 디자인 토큰(§5.2) 전체 구현 / 다크·라이트 테마 스위처 + FOUC 방지 / next-intl 5개 로케일 스캐폴드 / Firebase 프로젝트 2개(staging·prod) + Emulator / `env.ts` zod 검증 / CI 파이프라인(§16.2) / Vercel 연결

**DoD**
- [ ] `/`, `/en`, `/zh-CN`, `/zh-TW`, `/ja` 가 모두 렌더된다
- [ ] 테마 토글이 새로고침 후에도 유지되고 FOUC가 없다
- [ ] `npm run typecheck lint test i18n:check` 전부 통과
- [ ] 토큰 갤러리 페이지(`/dev/gallery`)에서 두 테마 색상·타이포가 확인된다
- [ ] Vercel Preview 배포 성공

## Phase 1 — UI 골격 (mock 데이터) (2주)
**작업**: 화면 A~E의 모든 컴포넌트를 §5.4 카탈로그대로 구현. 데이터는 `lib/mock/` 의 고정 픽스처. 타입은 실제 `Normalized*` 사용(R9). BottomNav·BottomSheet·LayerRail·TimelineSlider·TideChart 완성. 반응형 3단계(§5.5).

**DoD**
- [ ] 시안 4장과 나란히 놓고 구조·간격·위계가 일치한다 (§23.2 매핑 체크리스트 전 항목 ✓)
- [ ] 바텀시트가 열린 상태에서 지도 팬/줌이 된다 (R11)
- [ ] 모든 화면이 모바일/태블릿/데스크톱에서 깨지지 않는다
- [ ] 다크·라이트 두 테마 스크린샷 10장 첨부
- [ ] axe-core 위반 0건

## Phase 2 — 지점 날씨 실연결 (2주)
**작업**: KMA 어댑터(초단기실황/초단기예보/단기/중기) + Open-Meteo 폴백 / 좌표↔격자 변환 / 우선순위 엔진(§11.3) / Redis 캐시(§11.6) / `/api/v1/point`, `/forecast/*` / ConfidenceBadge / 출처 표기

**DoD**
- [ ] 지도 클릭 → 실제 현재/시간별/주간 데이터 표시
- [ ] 모든 카드에 출처·기준시각이 표시된다 (R7)
- [ ] 외부 API 장애를 의도적으로 주입해도 폴백으로 화면이 유지된다
- [ ] 캐시 히트율 로그 확인, 동일 지점 연속 요청 시 외부 호출 1회
- [ ] 어댑터 정규화 유닛테스트 커버리지 ≥ 80%

## Phase 3 — 물때 + 안전 (2주) ★ 차별화 1단계
**작업**: KHOA 조석예보·실측조위·수온·조류 어댑터 / 조석 일일 배치 선계산(쿼터 보호) / 물때 번호 계산(남해식) / TideChart 실데이터 / 자연어 변환기(§7.3) / 안전 모드(§14.3) / 오프라인 조석 캐시

**DoD**
- [ ] 협재·애월·한림 3개 지점에서 만조/간조 시각이 KHOA 공식값과 일치
- [ ] 자연어 문장이 5개 언어로 정확히 출력된다
- [ ] 기내모드(네트워크 차단)에서 즐겨찾기 지점의 물때·카운트다운이 계속 동작
- [ ] 갯바위 유형 지점 진입 시 SafetyBanner + 면책 문구 노출 (R10)
- [ ] 물때 용어 툴팁이 5개 언어로 제공된다

## Phase 4 — CCTV (1.5주) ★ 차별화 2단계
**작업**: Firestore CCTV 레지스트리 / hls.js + 네이티브 HLS 분기 / 지도 마커 / 바텀시트 통합(영상+날씨+물때) / 헬스체크 Function / 썸네일 Job / 재생 정책(§13.3)

**DoD**
- [ ] 제주 CCTV 10개 이상 등록, 목록·지도·상세에서 재생
- [ ] iOS Safari / Android Chrome / 데스크톱 Chrome·Safari 재생 확인
- [ ] 죽은 스트림을 3회 실패 후 자동 숨김 → 어드민에 반영
- [ ] 동시 재생이 1개로 제한되고, 화면 밖으로 나가면 정지한다
- [ ] 출처 표기가 모든 카드에 노출 (§13.5)

## Phase 5 — 지도 기상 레이어 (3주) ★ 가장 어려운 구간
**작업**: PoC-1·2 먼저 검증(§12.6) → GRIB 인제스트 워커(Cloud Run Job) / 격자 바이너리·타일 생성 / MapLibre CustomLayer 파티클 / 스칼라 래스터 셰이더 / 시간 보간 / 적응형 밀도

**DoD**
- [ ] 제주 전역 바람 파티클이 중급 모바일에서 ≥ 50fps
- [ ] 타임라인 드래그 시 보간이 끊기지 않는다
- [ ] 바람/강수/기온/파도 4개 레이어 전환이 500ms 이내 체감
- [ ] 저사양 기기에서 파티클이 자동 감소하고 앱이 멈추지 않는다
- [ ] 라이선스 검토 완료 — GPL 코드 미포함 확인 (§12.4)

## Phase 6 — 계정 · 마이페이지 · 알림 (2.5주)
**작업**: Firebase Auth(Google/Apple/Kakao/이메일링크/익명) + 세션 쿠키 / 게스트→정식 승계 / 마이페이지 전체(§9.4) / 활동 프로필 → 해석 엔진 개인화 연결 / 알림 규칙 빌더 + FCM + 평가 엔진(§14.2) / 로그북(스냅샷 자동 첨부)

**DoD**
- [ ] 비로그인 상태로 모든 조회 기능이 동작한다
- [ ] 게스트가 즐겨찾기 후 로그인하면 데이터가 승계된다
- [ ] 조건 알림이 실제로 발송되고, 중복 억제·조용시간이 동작한다
- [ ] 로그북 기록 시 당시 기상·물때 스냅샷이 자동 첨부된다
- [ ] 활동 프로필을 바꾸면 해석 문장·추천 순서가 바뀐다
- [ ] 데이터 내보내기/삭제 요청이 동작한다

## Phase 7 — 어드민 + 여행 콘텐츠 (2.5주)
**작업**: 어드민 전체(§10) / 여행 추천 엔진(§7.5) / 콘텐츠 CRUD + 다국어 편집 / 번역 매트릭스 / 감사 로그 / Remote Config 플래그

**DoD**
- [ ] operator 계정으로 CCTV 추가·수정·숨김이 코드 배포 없이 가능
- [ ] editor 계정으로 여행 장소를 5개 언어로 등록·발행 가능
- [ ] 권한 없는 역할이 해당 화면·API에 접근하면 차단된다 (UI + API + 보안규칙 3중)
- [ ] 모든 쓰기가 감사 로그에 before/after와 함께 남는다
- [ ] 비 조건을 주입하면 실내 코스가 상단으로 재정렬된다

## Phase 8 — 최적화 · 출시 준비 (2주)
**작업**: 성능 예산 달성(§16.1) / PWA(설치·오프라인 셸) / SEO(로케일별 sitemap·hreflang·구조화 데이터) / OG 이미지 / 접근성 최종 감사 / 부하 테스트 / 법적 문서 정비(§21) / 모니터링·알람

- [ ] PWA 설치 가능, 오프라인에서 즐겨찾기·물때 열람 가능

## 23.2 시안 → 구현 매핑 체크리스트 (Phase 1 DoD)

**시안 1 (지역 상세)**
- [ ] 상단 지도 + 바람 파티클 + 지명 라벨 + 현위치 도트
- [ ] 좌상단 원형 뒤로가기 + 지역명
