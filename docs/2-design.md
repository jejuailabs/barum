# 5. 디자인 시스템 — 첨부 시안에서 추출한 명세

> 이 섹션은 첨부된 4장의 시안(지역 상세 / CCTV·물때 / 여행 추천 / 메인 지도)을 코드가 바로 쓸 수 있는 토큰과 컴포넌트로 번역한 것이다. **모든 UI는 이 토큰만 사용한다 (R6).**

## 5.0 디자인 원칙 (시안에서 읽히는 규칙)

| 원칙 | 시안 근거 | 구현 규칙 |
|---|---|---|
| **1. 지도가 주인공** | 4장 중 2장이 전면 지도, 나머지도 지도/영상 위에 카드가 얹힘 | 콘텐츠는 지도를 덮되 가리지 않는다. 바텀시트 기본 높이는 뷰포트의 55%, 상단 45%는 항상 지도 |
| **2. 어두운 바다, 밝은 데이터** | 배경은 심해색, 숫자·아이콘은 발광하는 시안/블루 | 배경은 저채도 딥네이비, 강조는 `--accent` 계열 단 하나 |
| **3. 카드 = 정보 단위** | 모든 정보가 라운드 20px 카드 안에 들어감 | 카드 밖에 떠 있는 텍스트를 만들지 않는다 |
| **4. 숫자는 크게, 라벨은 작게** | `23°`(64px) vs `구름 조금`(22px) vs `체감 24°`(14px) | 3단계 위계를 지킨다: Display / Title / Caption |
| **5. 문장이 숫자 옆에 있다** | "지금, 제주 애월은 바람이 적당하고 파도가 안정적이에요" | 모든 요약 카드는 우측에 해석 문장 슬롯을 갖는다 |
| **6. 빛나는 활성 상태** | 활성 레이어 버튼·중앙 FAB만 글로우 | 글로우(box-shadow 확산)는 **화면당 최대 2곳** |
| **7. 손가락 우선** | 원형 버튼 68px, 하단 탭 대형 | 모든 터치 타깃 ≥ 44×44px, 주요 액션 ≥ 56px |

## 5.1 브랜드 시각 언어

- **로고/워드마크**: `바름닷컴` — 물결 3선 아이콘(`≈` 형태를 부드럽게) + 텍스트. 중앙 FAB 안에서는 물결 아이콘만.
- **아이콘 스타일**: 스트로크 2px, 라운드 캡, 채움 없음. 예외: 날씨 아이콘은 컬러 채움(태양 앰버, 구름 화이트~그레이, 빗방울 블루).
- **아이콘 세트**: Lucide React 기본 + 날씨/해양 전용 커스텀 SVG 세트(`/public/icons/weather/*.svg`).
- **이미지 처리**: 사진 카드는 상단 40% 투명 → 하단 80% 딥네이비 오버레이 그라디언트(텍스트 가독성 확보).

**라이트 모드 추가 규칙**
1. 라이트 모드에서 **글로우 효과는 절반 이하**로 줄인다(흰 배경에서 번져 보임).
2. 지도 베이스맵도 테마에 따라 교체한다: 다크 → 위성/다크 벡터, 라이트 → 밝은 벡터 지도. 단, **기상 컬러 오버레이의 컬러맵은 두 모드에서 동일**(데이터 일관성).
3. 지도 위 떠있는 컨트롤은 라이트 모드에서 `--surface-glass` + `--border-strong` 조합으로 윤곽을 확보한다.
4. CCTV·사진 카드는 라이트 모드에서도 이미지 위 텍스트에 다크 스크림을 유지한다.

### 5.2.3 테마 전환 구현

```
- 저장소: localStorage `barum.theme` = 'system' | 'light' | 'dark'  (로그인 시 Firestore users/{uid}.settings.theme 로 동기화)
- 적용: <html data-theme="dark|light"> 속성. system 인 경우 matchMedia('(prefers-color-scheme: dark)') 구독
- FOUC 방지: app/layout.tsx 의 <head> 에 인라인 blocking script 로 첫 페인트 전에 data-theme 설정
- 전환 애니메이션: 200ms ease, 단 prefers-reduced-motion 이면 0ms
- 기본값: 'system' (제품 성격상 다크가 기본처럼 보이지만, 강제하지 않는다)
```

### 5.2.6 모션

```
duration: instant 0ms / fast 150ms / base 250ms / slow 400ms / sheet 320ms
easing:   standard cubic-bezier(.2,.8,.2,1)
          enter    cubic-bezier(0,.8,.2,1)
          exit     cubic-bezier(.4,0,1,1)

- 바텀시트: spring 느낌의 320ms, 스냅 포인트 [12%(핸들만), 55%(기본), 92%(전체)]
- 레이어 전환: 기존 레이어 fade-out 150ms → 신규 fade-in 250ms, 지도는 리렌더 없음
- 타임라인 드래그: 값 변화는 requestAnimationFrame 스로틀, 격자 보간은 60fps 목표
- 숫자 변화: 카운트업 애니메이션 금지 (오독 유발). 즉시 교체 + 150ms opacity fade
- prefers-reduced-motion: reduce → 파티클 애니메이션 정지(정적 화살표 필드로 대체), 모든 transition 0ms
```

## 5.3 접근성 기준 (G5 대응 — 검증 자동화 대상)

| 항목 | 기준 |
|---|---|
| 텍스트 대비 | 본문 4.5:1, 18px 이상 굵은 글씨 3:1 — **다크/라이트 양쪽 모두** |
| 터치 타깃 | 최소 44×44px, 하단 탭·FAB 56px 이상 |
| 포커스 | 모든 인터랙티브 요소에 `:focus-visible` 2px `--accent` 아웃라인 + 2px 오프셋 |
| 스크린리더 | 지도는 `role="application"` + 대체 수단(지점 리스트 뷰) 제공. 모든 아이콘 버튼에 `aria-label`(i18n 키) |
| 색 단독 의존 금지 | 상태는 색 + 아이콘/텍스트 병기 (LIVE 도트 옆 "LIVE" 텍스트, 신뢰도 배지에 텍스트) |
| 모션 | `prefers-reduced-motion` 준수 (§5.2.6) |
| 검증 | CI에서 `@axe-core/playwright` 로 주요 5개 화면 × 2개 테마 = 10케이스 자동 검사 |

## 5.4 컴포넌트 카탈로그 (시안에서 추출)

> 모든 컴포넌트는 `src/components/ui/` 또는 도메인 폴더에 위치. Storybook(또는 `/dev/gallery` 라우트)에 다크·라이트 두 스토리를 필수 등록한다.

### 5.4.1 GlassControl — 지도 위 떠있는 컨트롤 공통 셸
```
배경 --surface-glass, backdrop-filter: blur(20px) saturate(1.2)
테두리 1px --border-subtle, radius --r-pill 또는 --r-lg
shadow e3
용도: 검색바, 뒤로가기 버튼, GPS 버튼, 줌 컨트롤, 위치 칩
```

### 5.4.2 LayerRail — 우측 레이어 선택 레일
```
위치: 지도 우측, top: safe-area + 88px, gap 12px, right 16px
아이템: 원형 64~68px, 아이콘(24px) + 라벨(label-s, 아이콘 아래 2px)
상태:
  - 비활성: --surface-glass, 아이콘/라벨 --text-secondary
  - 활성:   background --accent-grad, 아이콘/라벨 --text-on-accent, shadow e4(--accent-glow)
아이템 목록(지도 홈): 바람 / 강수 / 기온 / 파도 / 물때   ← 시안 4
아이템 목록(지역 상세 축소 상태): 바람 / 강수 / 파도      ← 시안 1 (3개로 축약)
동작: 단일 선택. 탭 시 haptic(지원 시) + 150ms 스케일 0.94 → 1.0
접근성: role="radiogroup", 각 버튼 role="radio" aria-checked
```


1. 지점 선택 헤더 (GlassControl pill `협재 해변 >` + `실시간` 배지 + 행정주소)
2. **현재 상태 3분할**: 현재 기온·상태 / 풍향·풍속 / 파고
3. **오늘의 조위 카드** (§5.4.8 TideChart)
   - 헤더: `오늘의 조위 (협재)` + 우측 `만조까지 1시간 22분 >` pill
   - 곡선 + 만조/간조 포인트 라벨
4. **TideStrip**: 물때(8물) / 일출 06:19 / 일몰 18:34 / 월출 14:02 / 수온 24.0°
5. **자연어 상태 문장** (G7 핵심)
   ```
   지금은 물이 차오르는 중이에요.  (밀물 / 창조)
   만조까지 1시간 22분 남았고, 다음 간조는 13:51이에요.
   오늘은 8물 — 물살이 제법 세게 흐르는 날입니다.
   ```
6. **안전 카드** (G8): 갯바위/갯벌 진입 시 복귀 권장 시각 계산
   ```
   복귀 권장: 12:51 (간조 1시간 전)
   남은 시간 [ 03:10 ] 카운트다운
   [안전 알림 받기]  [해양경찰 122]
   ```
7. **7일 물때표**: 날짜별 만조/간조 시각 + 물때 번호 리스트
8. **조류 정보**(데이터 제공 지점만): 방향 나침반 + 유속
9. 용어 사전 진입: "물때 용어가 궁금하다면 >"

**초보/전문 모드 토글** (헤더 우측)
- 초보: 자연어 문장 + 곡선 중심, 몇물/사리/조금은 툴팁으로만
- 전문: 조위 수치표, 조석 계수, 조류 벡터, 관측 vs 예측 편차

**오프라인 대응** (G8): 즐겨찾기한 지점의 향후 7일 조석 예보를 IndexedDB에 캐시. 네트워크 단절 시 "오프라인 · 예측값 기준" 배너와 함께 표시.

## 6.4 화면 D — CCTV (`/[locale]/cctv`) — 시안 2 상단부 (G6, G12)

**허브 화면**
- 상단: 검색바 + GPS 버튼 (GlassControl)
- 위치 칩 + `실시간` 상태 배지
- **대표 CCTV 카드** (§5.4.10): 선택된 지점의 라이브
- 그 아래 **날씨/물때 요약** — CCTV와 같은 화면에 있는 것이 핵심 차별점 (G12)
- 하단: 인근 CCTV 그리드(2열, 썸네일 + 장소명 + 상태 도트), 거리순/인기순 정렬
- 목록/지도 토글

**재생 정책** (§13.3 참조)
- 진입 시 **자동재생 금지**, 썸네일 + 재생 버튼
- 재생은 한 번에 1개 스트림만. 새 스트림 재생 시 이전 스트림 `destroy()`
- Safari/iOS: 네이티브 HLS(`<video src>`) / 그 외: `hls.js`
- 오류 3회 연속 시 해당 CCTV `status: degraded` 로 표시하고 어드민에 이벤트 전송

**전체화면 뷰** (`/cctv/[id]`)
- 영상 최대화 + 하단 오버레이에 기온·바람·파고·물때·수온·다음 만조/간조
- 가로모드 지원, 화면 꺼짐 방지(Wake Lock API, 최대 10분)
- 공유 버튼(딥링크 + OG 이미지는 최신 썸네일)

## 6.5 화면 E — 여행/추천 (`/[locale]/travel`) — 시안 3 (G10)

**상단 히어로**
- 배경: 시간대별로 교체되는 제주 풍경 사진(아침/낮/노을/밤) + 하단 그라디언트
- 타이틀 `오늘 어디 갈까?`(title-xl) / 서브 `날씨와 바다 상태를 기준으로 추천`(body-s)
- 우상단: 기준 위치 칩

**카테고리 칩**: `서핑 | 낚시 | 드라이브 | 카페` (+ 확장: 해변, 오름, 실내)
- 활성 칩은 --accent-grad. 선택에 따라 아래 추천 목록과 정렬 기준이 바뀜

**추천 카드 목록** (§5.4.12) — 각 카드는 **왜 추천인지 수치로 보여준다**
```
곽지 해변 | 에메랄드빛 바다와 부드러운 파도
  파도 1.0m · 바람 적당 · 지금 23°     [서핑 추천 >]
도두 무지개해안 | 노을이 아름다운 제주 대표 드라이브 코스
  노을 좋음 · 바람 약함 · 지금 22°     [드라이브 추천 >]
한림항 | 초보자도 즐기기 좋은 생활 낚시 명소
  만조 18:20 · 낚시 무난 · 지금 21°    [CCTV 보기 >]
```

**실시간 CCTV 연결 배너**: 아이콘 + 타이틀 + 체크 칩 3개(해변 상황 / 파도 높이 / 현장 날씨) + 재생 버튼

**오늘의 추천 코스**: 가로 스크롤 카드, 배지 칩(`반나절 코스`, `일몰 명소`, `비 와도 OK`)
- **비/강풍 조건에서는 실내 코스가 자동으로 상단 배치** (G10 핵심)

**추천 로직**: `§7.5` 매칭 점수. 콘텐츠(장소·코스)는 Firestore `places` / `courses` 컬렉션에서 어드민이 관리 (§10.4).
