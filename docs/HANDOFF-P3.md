# Phase 3 인수인계

담당: Sol. 2026-09-23.

## DoD

- [ ] 협재·애월·한림 KHOA 공식값 대조 — `KHOA_SERVICE_KEY` 미제공으로 외부 검증 대기.
- [x] 상승·하강·만조·간조 자연어 및 물때 설명을 5개 언어로 제공한다.
- [x] IndexedDB에 조석 예보를 저장하고 네트워크 실패 시 저장값과 오프라인 배너를 사용한다.
- [x] 갯바위 지점의 복귀 권장 시각, 면책 문구, 구명조끼 안내, 해양경찰 122 동선을 제공한다.
- [x] 몇물·사리·조금 툴팁을 5개 언어로 제공한다.

KHOA 고·저조 어댑터, 사전 매핑된 최근접 관측소, 24시간 캐시 API, 남해식 물때 계산, 자연어 변환, 안전 복귀 시각, Open-Meteo 해수면 모델 폴백을 구현했다. 모델 폴백은 공식 조석으로 표시하지 않으며 `diverging/partial` 상태와 참고용 경고를 유지한다.

공식 대조를 완료하려면 공공데이터 활용 승인을 받은 `KHOA_SERVICE_KEY`를 서버 환경에 등록해야 한다. 등록 후 `/api/v1/tide/{spotId}?date=YYYY-MM-DD`에서 `KHOA_TIDE_PRED` 출처와 세 지점의 고·저조 시각을 확인한다.
