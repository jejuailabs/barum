- 물때/CCTV/여행/더보기: 조위 곡선과 5분할 스트립, CCTV 상태·주변 목록, 여행 추천 카드·코스, 마이페이지 진입 골격.

## Phase 2 시작점

`docs/00-INDEX.md`의 Phase 2 문서만 읽고 시작한다. 우선 KMA 초단기실황/예보 및 Open-Meteo 폴백 어댑터를 현재 `Normalized*` 계약에 연결한다. UI가 외부 응답 타입을 가져오지 않게 유지하고, 모든 실제 카드에 출처와 기준 시각을 표시한다. 외부 장애 주입, 좌표↔격자 변환, 캐시 히트 검증이 Phase 2 핵심이다.

지도 전면 기상 레이어는 Phase 5 범위다. Phase 2에서 지점 API 호출을 반복해 격자처럼 그리지 않는다. CCTV 실연결은 Phase 4, Firebase Auth와 개인 데이터는 Phase 6 범위다.
